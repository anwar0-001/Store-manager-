# Store Manager

واجهة عربية لإدارة متجر إلكتروني، مبنية بـ HTML وCSS وJavaScript دون اعتماد على إطار عمل.

## تشغيل الموقع

افتح `index.html` في متصفح حديث. تعرض الواجهة لوحة تحكم عربية RTL، وتتيح إدارة المنتجات (إضافة وتعديل وحذف والبحث والتصفية)، وتغيير حالات الطلبات، واستعراض العملاء والتحليلات.

المنتجات والطلبات والحملات التي تغيّرها تُحفظ في `localStorage` على المتصفح والجهاز الحاليين.

> هذه نسخة تجريبية ببيانات توضيحية، وليست متجرًا متصلًا بخادم. لا يوجد تسجيل دخول فعلي أو مزامنة بين الأجهزة أو قاعدة بيانات أو دفع وشحن. لا تستخدمها لحفظ بيانات عملاء حقيقية.
